# Changelog

All notable changes to DMSI are documented in this file. The project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html) for its maintained static application.

## 2.2.0 - 2026-09-04

### Added

- A live four-step ranking gauge that shows the current rank and choices remaining
- Automated tests for every ranking-progress state

### Changed

- Reframed the ranking language as Most, More, Less, and Least like me
- Changed the ranking palette to green, light green, yellow-orange, and red
- Made rank language primary and point values secondary inside answer cards
- Kept unselected answers visually neutral until hover or selection
- Moved repeated ranking instructions into an assistive-technology live region

## 2.1.0 - 2026-09-04

### Added

- Persistent light and dark themes with system-aware first use
- Complete plain-text results export, print layout, and copyable summary
- Search-engine metadata, social sharing metadata, structured data, a web app manifest, and crawlable discovery files
- PNG social preview and application icons
- Contributor, security, support, conduct, citation, and project-method documentation
- Structured issue forms, a pull-request template, code ownership, and GitHub Actions dependency updates
- Automated metadata and community-health validation

### Changed

- Expanded repository metadata and README navigation
- Improved footer authorship, licensing, privacy, and project links

## 2.0.0 - 2026-09-04

### Added

- Complete responsive redesign for desktop and mobile use
- One-question-at-a-time forced-ranking workflow
- Local progress saving, undo, back navigation, and restart controls
- Practical primary, blended, and counterweight interpretations
- Automated scoring, content, privacy, and integrity checks
- GitHub Pages validation and deployment workflow
- Legacy-link forwarding from `dmsiform.html`

### Changed

- Replaced the original table-based questionnaire with a semantic, accessible application
- Separated scoring, content, export, theme, and interface logic into testable modules

## 1.0.0 - 2024-10-17

### Added

- Original browser-based Decision-Making Style Inventory
