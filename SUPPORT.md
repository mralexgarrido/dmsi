# Support

## Using DMSI

Start with the [live assessment](https://mralexgarrido.github.io/dmsi/) and the [project README](README.md). The README explains scoring, classroom use, privacy, local development, and deployment.

For facilitation context, read [Unlocking Creative Potential: The 4 Decision-Making Styles Every Marketing Team Needs](https://www.marketingsciencelab.org/p/improve-creative-team-performance-decision-making).

## Get help or report a problem

- Search [existing issues](https://github.com/mralexgarrido/dmsi/issues) before opening a new one.
- File a [bug report](https://github.com/mralexgarrido/dmsi/issues/new?template=bug_report.yml) for behavior that can be reproduced.
- Submit a [feature request](https://github.com/mralexgarrido/dmsi/issues/new?template=feature_request.yml) for a proposed improvement.
- Report vulnerabilities through [GitHub Security Advisories](https://github.com/mralexgarrido/dmsi/security/advisories/new), not a public issue.

When requesting help, include the browser and operating system, the page or question where the problem occurred, the expected result, and the observed result. Do not attach a participant's exported answers without their informed permission.

## Scope

DMSI is an educational self-reflection tool. The project does not provide psychological, clinical, employment, legal, or diagnostic advice. Questions about administering a validated instrument or making high-stakes decisions are outside the support scope.
